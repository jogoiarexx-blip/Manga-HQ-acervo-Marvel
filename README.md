## Estrutura

As HQs estão em PDF. O workflow gera automaticamente uma capa WebP usando a primeira página, conta as páginas e reconstrói o `catalogo.json`.

O GitHub Pages publica somente o índice e o catálogo. PDFs e capas ficam no repositório e são carregados via `raw.githubusercontent.com`.
